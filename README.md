# BlockShard

BlockShard enables real-time, distributed data processing through an auto-scaling, cloud-native platform framework.

BlockShard is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/BlockShard.git`
2. `cd BlockShard`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
